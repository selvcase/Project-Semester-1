## Deskripsi Project
Proyek ini merupakan proyek awal saya dalam mempelajari dan menerapkan bahasa pemrograman C++ selama Semester I perkuliahan. Proyek pertama yang ingin saya kembangkan adalah kalkulator sederhana berbasis C++ yang dapat melakukan operasi aritmetika dasar, seperti penjumlahan, pengurangan, perkalian, dan pembagian.

Melalui proyek ini, saya berharap dapat meningkatkan kemampuan pemrograman, menerapkan logika komputasi, memahami penggunaan variabel, operator, percabangan, dan perulangan, serta membiasakan diri menggunakan GitHub sebagai sarana dokumentasi dan pengembangan proyek.

## Langkah-langkah 
1. Membuat repository GitHub sebagai tempat penyimpanan dan dokumentasi proyek.
2. Menyusun rencana program kalkulator dan menentukan fitur yang akan dikembangkan.
3. Menulis kode program menggunakan bahasa pemrograman C++.
4. Menerapkan operasi aritmetika dasar, yaitu penjumlahan, pengurangan, perkalian, dan pembagian.
5. Menguji program untuk memastikan setiap operasi berjalan dengan benar.
6. Memperbaiki kesalahan atau bug yang ditemukan selama pengujian.
7. Mengunggah dan memperbarui kode program ke repository GitHub.
8. Mengembangkan fitur tambahan secara bertahap sesuai dengan kemampuan yang telah dipelajari.
